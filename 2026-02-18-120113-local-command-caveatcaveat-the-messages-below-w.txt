     Playwright E2E Tests for Cravings App

     Context

     The app has no automated tests beyond a trivial CRA Jest test. Adding
     Playwright E2E tests will cover the core user flows: auth, search,
     favorites, newsfeed, profile, team, and logout.

     Setup

     - Install @playwright/test as a root dev dependency
     - Create playwright.config.js at the project root (base URL:
     http://localhost:3000)
     - Create tests/ directory at the root
     - Create tests/helpers.js with a shared login utility
     - Add test:e2e script to root package.json

     Files to Create

     playwright.config.js

     - Base URL: http://localhost:3000
     - Browsers: Chromium only (keep it fast)
     - Timeout: 30s per test
     - Expects dev servers already running (npm run start:dev)

     tests/helpers.js

     - login(page, username, password) — reusable login helper that
     navigates to /login, fills form, submits, and waits for redirect to
     /search

     tests/auth.spec.js

     - Login with valid credentials (test/test) → redirects to /search
     - Login with empty fields → toast "Please enter your username and
     password"
     - Login with wrong credentials → toast "Incorrect credential"
     - Auth guards: visiting /search, /favorites, /newsfeed, /profile, /team
      while logged out → redirects to /login

     tests/search.spec.js

     - Log in → search "Chicago" → restaurant card appears
     - Click favorite (heart) button → toast confirms added, appears in
     sidebar
     - Click skip button → next restaurant shows

     tests/favorites.spec.js

     - Log in → navigate to /favorites
     - If favorites exist, cards display with name and remove button
     - Remove a favorite → card disappears

     tests/newsfeed.spec.js

     - Log in → navigate to /newsfeed
     - Feed items display with username, activity type, restaurant name

     tests/profile.spec.js

     - Log in → navigate to /profile → shows user details (username, name,
     email, zip)
     - Click "Edit Profile" → update a field → save → verify update on
     profile page

     tests/team.spec.js

     - Log in → navigate to /team → user cards display

     tests/logout.spec.js

     - Log in → click Logout in navbar → "You have been logged out" message
     - After logout, visiting /search redirects to /login

     Key Details

     - Test user: Seeded user test / test
     - Selectors: Use name attributes on inputs (e.g., [name="username"]),
     CSS classes (.auth-btn, .nav-link, .filter-select), and text content
     - Toasts: Assert on .Toastify__toast text for success/error messages
     - External API: Search tests depend on Geoapify; use "Chicago" as
     location with reasonable timeouts
     - Auth: Session-based via cookies — Playwright handles this
     automatically

     Verification

     1. Start the app: npm run start:dev
     2. Run tests: npx playwright test
     3. All tests should pass against local app with seeded database
